# ASOEMPRE BUCARAMANGA - Prototipo Web

Este repositorio contiene la versión interactiva y responsive del prototipo de comercio electrónico y modelo solidario para la **Asociación de Emprendedores de Bucaramanga (ASOEMPRE)**, desarrollado para el **Curso Institucional III (Gestión Solidaria)** de la **Universidad Cooperativa de Colombia (UCC)**.

## 🚀 Instrucciones de ejecución local

1. Clonar el repositorio o descomprimir los archivos.
2. Instalar dependencias:
   ```bash
   pnpm install
   # o con npm:
   npm install
   ```
3. Iniciar el servidor de desarrollo:
   ```bash
   pnpm dev
   # o con npm:
   npm run dev
   ```
4. Abre la dirección `http://localhost:5173` en tu navegador.

## 📦 Despliegue en Vercel / Netlify
- **Vercel:** Conecta tu repositorio de GitHub directamente e importa este proyecto. Vercel detectará Vite automáticamente.
- **Netlify:** Ejecuta `pnpm build` y arrastra la carpeta `dist` generada a la consola de Netlify Drop.
